FoodLoop Starter Website
========================

Files:
- index.html: homepage
- donations.html: sample donation listings with search, category filter, sorting
- login.html: demo login form
- register.html: demo registration form
- styles.css: responsive styling and Arabic font (Cairo)
- app.js: JavaScript interactions and Arabic/English language toggle
- foodloop-logo.png: FoodLoop logo mark

How to run:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Recommended: use the Live Server extension and open index.html.

The language selection is saved in localStorage. Google Fonts requires an internet connection; fallback fonts are included.
This is a front-end prototype only. Forms do not authenticate or save accounts, and donation listings are sample data. A backend and database will be needed later.
